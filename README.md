# Weather App

A small React weather dashboard. Pick a city from the dropdown to see current temperature, wind, UV index, precipitation and a live update log. Data comes from the free [Open-Meteo](https://open-meteo.com/) API (no API key needed) and refreshes every minute.

## Run locally

```bash
npm install
npm start
```

Then open [http://localhost:3000](http://localhost:3000).

Built with Create React App, SWR and react-icons.
